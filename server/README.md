# Backend — שרת מערכת המשלוחים

שרת ה-API של מערכת מייה אינספיריישן. מנהל את התקשורת עם בסיס הנתונים ועם API של חברת השליחויות אוריין.

## 🛠️ טכנולוגיות

- **Node.js** (גרסה 18 ומעלה)
- **Express** — framework לבניית ה-API
- **SQLite** — מסד נתונים מקומי
- **dotenv** — טעינת משתני סביבה

## 📦 התקנה

### לפני שמתחילים — וודאי ש-Node.js מותקן

```bash
node --version
```

אמור להחזיר משהו כמו `v20.x.x` או חדש יותר. אם לא — להתקין מ-https://nodejs.org/

### שלב 1 — התקנת תלויות

מתוך התיקייה `server/`:

```bash
npm install
```

זה יוריד את כל הספריות הנדרשות לתיקייה `node_modules/` (לא נכנסת ל-Git).

### שלב 2 — הגדרת משתני סביבה

יש להעתיק את הקובץ `.env.example` ל-`.env`:

```bash
cp .env.example .env
```

ואז למלא את הערכים בקובץ `.env` החדש (לפי הוראות בתוכו).

⚠️ **חשוב:** הקובץ `.env` מכיל סודות (סיסמאות, מפתחות) ולעולם לא יעלה ל-Git.

## 🚀 הפעלה

### מצב פיתוח (מומלץ — מתעדכן אוטומטית בכל שינוי קוד)

```bash
npm run dev
```

### מצב רגיל

```bash
npm start
```

השרת יתחיל לרוץ על **http://localhost:3001**

## 🔍 בדיקה שהשרת עובד

אחרי שהרצת אותו, פתחי בדפדפן את:

```
http://localhost:3001/api/health
```

אמורה לראות JSON שכזה:

```json
{
  "status": "ok",
  "message": "שרת מייה אינספיריישן פועל",
  "timestamp": "2026-05-05T12:00:00.000Z",
  "uptime": 1.234
}
```

## 📁 מבנה התיקיות

```
server/
├── src/
│   ├── index.js          # נקודת הכניסה — מפעיל את השרת
│   ├── routes/           # הנתיבים שה-Frontend פונה אליהם
│   │   └── health.js     # בדיקת חיים
│   ├── services/
│   │   └── orian/        # התקשורת עם API של אוריין (יתווסף)
│   ├── db/               # SQLite (יתווסף)
│   └── middleware/
│       └── errorHandler.js  # טיפול בשגיאות
├── .env.example          # תבנית למשתני סביבה
├── .env                  # משתני סביבה אמיתיים (לא ב-Git!)
├── package.json          # הגדרות הפרויקט והתלויות
└── README.md             # הקובץ הזה
```

## 🧱 מודולים שיתווספו בהמשך

- `routes/auth.js` — התחברות והרשמה
- `routes/shipments.js` — ניהול משלוחים
- `services/orian/` — אינטגרציה עם API של אוריין
- `db/schema.js` — מבנה טבלאות SQLite
